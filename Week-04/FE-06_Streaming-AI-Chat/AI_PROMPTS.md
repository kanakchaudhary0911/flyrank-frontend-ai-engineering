# AI Prompts

## Architecture
Design a Next.js + TypeScript streaming AI chat using the AI SDK and Google
Gemini. Keep the model configuration and system prompt in one server-side module.

## UI
Build a responsive chat interface with user/assistant messages, thinking
indicator, streaming state, stop control, accessible input, and mobile support.

## Robustness
Implement scroll-aware auto-scroll: stay pinned only while the user is near
the bottom and provide a jump-to-latest control when they scroll upward.
