## What I Learned

- Setting up a reliable development environment is an important foundation for AI-assisted development.
- Git and GitHub provide a structured way to manage project changes and maintain a clear development history.
- Conventional Commits make Git history easier to understand and maintain.
- AI coding assistants can be used for documentation review as well as development tasks.
- AI-generated suggestions should be reviewed before applying them to the project.
- Keeping project conventions documented in `CLAUDE.md` helps maintain consistency when working with AI assistants.
