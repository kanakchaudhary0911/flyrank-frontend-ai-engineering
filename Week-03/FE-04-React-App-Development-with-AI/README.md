# FE-04 – React App Development with AI

## Overview

This assignment focuses on building a practical React application independently while using AI as a development assistant.

The application developed for this assignment is a **Job Application Tracker**, designed to help users organize and manage their job applications in one place.

The project demonstrates how AI can support planning, implementation, debugging, testing, and refinement while keeping the developer responsible for reviewing and improving the final implementation.

---

## Objectives

- Build a functional React application
- Use AI as a development assistant
- Practice component-based React development
- Implement practical application features
- Use LocalStorage for persistent data
- Practice debugging and code review
- Document AI prompts and assistance
- Identify and perform manual improvements

---

## Project

### Job Application Tracker

The Job Application Tracker is a responsive web application for managing job application records.

### Key Features

- Add job applications
- Edit application details
- Delete applications
- Search applications
- Filter applications
- Track application status
- Persist data using LocalStorage
- Responsive user interface
- Dark mode / theme support
- Reusable React components
