# Job Application Tracker

A clean, responsive React application for organizing job applications.

## Features

- Add job applications
- Edit applications
- Delete applications
- Search by company or role
- Filter by application status
- LocalStorage persistence
- Light / dark mode
- Responsive layout
- Application statistics

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Browser LocalStorage

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
