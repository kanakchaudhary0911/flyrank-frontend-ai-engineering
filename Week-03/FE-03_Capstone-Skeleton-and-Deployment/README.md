# FE-03 – Capstone Skeleton & Deployment

## Kanak Chaudhary Developer Portfolio

A responsive, recruiter-friendly developer portfolio built with **Next.js, React, TypeScript, and CSS**.

The project establishes the initial portfolio structure, reusable navigation, multiple routes, health-check functionality, responsive styling, and deployment-ready configuration.

---

## Objective

Build the initial skeleton of a professional developer portfolio and prepare the application for production deployment.

The project focuses on establishing a maintainable frontend structure that can be extended with projects, case studies, and additional portfolio content.

---

## Included

- Home page
- Projects / Case Studies page
- About page
- Contact page
- Health page
- `/api/health` JSON endpoint
- Responsive navigation
- Responsive page layout
- Project metadata
- Production build configuration
- AI-assisted development workflow
- Deployment documentation

---

## Routes

| Route | Purpose |
|---|---|
| `/` | Home |
| `/projects` | Projects / Case Studies |
| `/about` | About |
| `/contact` | Contact |
| `/health` | Application Health Check |
| `/api/health` | JSON Health Check API |
