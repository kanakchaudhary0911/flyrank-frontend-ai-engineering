# AI Assistance

AI was used as a development assistant throughout the implementation.

## Where AI Helped

- Project planning and feature selection
- React component breakdown
- Form structure
- Search and filtering logic
- LocalStorage implementation
- Responsive CSS ideas
- Dark mode implementation
- Debugging and refactoring suggestions
- Documentation structure

## Developer Responsibility

AI-generated suggestions were reviewed before implementation. The final application was manually tested and adjusted for usability, layout, responsiveness, and code organization.

The purpose of AI use was to accelerate development while keeping human review and decision-making in the workflow.
