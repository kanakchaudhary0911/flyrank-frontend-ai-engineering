# AI Prompts Used

## Prompt 1 — Project Planning

Create a simple React project for a Week 3 AI-assisted development assignment. Build a Job Application Tracker that is professional, responsive, and achievable within a few hours.

Required features:
- Add application
- Edit application
- Delete application
- Search
- Status filter
- LocalStorage
- Dark mode

Keep the architecture simple and use reusable React components.

## Prompt 2 — Component Structure

Suggest a clean React component structure for a Job Application Tracker without using a backend or external API.

## Prompt 3 — Application Form

Create a reusable React form for adding and editing job applications with company name, role, location, and status.

## Prompt 4 — Search and Filter

Implement client-side search by company or job role and filtering by application status using React state.

## Prompt 5 — LocalStorage

Implement a small LocalStorage utility so job applications persist after refreshing the browser.

## Prompt 6 — Responsive UI

Suggest a clean responsive CSS layout for a professional job application tracker that works on desktop and mobile.

## Prompt 7 — Refactoring

Review the generated React structure and identify opportunities to improve readability, component reuse, state management, and user experience.
