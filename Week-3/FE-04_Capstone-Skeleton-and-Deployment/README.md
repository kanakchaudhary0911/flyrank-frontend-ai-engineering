# FE-04 — Capstone Skeleton & Deployment

## Kanak Chaudhary Developer Portfolio

A responsive, recruiter-friendly portfolio built with Next.js, React, TypeScript, and CSS.

### Included
- Home, Projects, About, Contact, and Health pages
- `/api/health` JSON endpoint
- Responsive navigation and layout
- Production build configuration
- AI-assisted workflow documentation
- Deployment instructions

### Run
```bash
cd app
npm install
npm run dev
```

### Verify
```bash
npm run build
npm start
```

### Routes
`/` · `/projects` · `/about` · `/contact` · `/health` · `/api/health`

### AI assistance
AI was used for planning route structure, drafting UI/content, responsive styling ideas, documentation, and implementation review. Final code was reviewed and adapted for the project requirements.
